## 运行

需要 Go 1.23+，无第三方依赖，默认使用内置 Mock 模型，不需要 api key：

```bash
go run ./02
```

换成真实模型（任何 OpenAI 兼容接口）：

```bash
go run ./02 -real \
  -base-url https://api.deepseek.com/v1 \
  -api-key $LLM_API_KEY \
  -model deepseek-chat
```

## 约定

- **每个章节 demo 自包含**：不跨目录 import，复制单个目录即可独立运行
- **Mock 优先**：默认跑通全链路，方便对照文章输出；真实模型是可选路径
- **只演示文章讲到的能力**：不提前引入下一章的概念（比如第 2 章没有 ReAct 循环、没有并发）
